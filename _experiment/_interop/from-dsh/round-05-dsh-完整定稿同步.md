## 二、round-03 之后的新增定稿（用户十轮提问，Q9~Q31）

### 1. 开发纪律（用户定）
**主线串行 + 旁支并行 + 末次全流程验收**：
- 主线（P0-2 回读领域 → P0-3 真实只读回读 → P0-3.5 M4契约 → P0-4 最小真实写入）严格串行，前环过硬验收才解锁下一环；
- 旁支（选品/素材/上架其余）可在 P0-1 地基后并行开发，接入主线时须回主线门禁；
- 全部完成后做一次端到端总验收（选品→素材→上架→托管→两轮回读→ROI 回写）才算完成。

### 2. 闸门机制（用户定，替代原 waiting_confirmation 人工审批语义）
**自动质量门禁 + 自动回修 + 超限人工强审**：
- 达标自动放行；未达标系统自动修 → 重回闸门；自动修 N 次仍不达标/无法自动修 → 转人工队列强审；
- 每个闸门达标规则/修正方式/重试上限 N 全部配置化；
- 选品/素材/上架/托管/回读各模块闸门都是本机制的实例。

### 3. 选品引擎（完全放开 + 四重过滤 + 可审计人工层，§4）
- 店类目/SKU 完全放开，选到多少算多少；
- 过滤1 合规/类目白名单（前置硬过滤）；过滤2 榜单快照（有米云/罗盘，存时间/来源/账号/原始证据）；过滤3 页面可见信号（缺失标记 field_missing 不补造）；过滤4 供应链毛利（一期最硬准入）；
- 人工初筛必须写明理由，可审计非黑箱；
- 状态分层 discovered→scored→approved→material_ready→listing_ready；
- 产出节奏：定时批次为主+事件触发为辅；候选池限额（30/10/3/1，配置化）；
- 错误分类表 + 来源健康度独立维护。

### 4. 素材模块（来源优先级 + material_ready + 风险分层审核，§5）
- 来源优先级：供应商授权原始素材(P0主源) > 自有/已购授权 > 全网采集仅作发现线索；**可抓到≠可用**；
- material_ready = 存在可执行、可追溯、可合规获取的素材路径（含 rights_status 枚举），不是素材已审核；缺源标记 MATERIAL_GAP；
- material_ready（选品侧：有无素材来源）与素材闸门（具体文件达标）两层分工；
- 素材人工审核按风险分层：新源/AI/首次/高风控/拒审重提强制人工；纯格式转换/同租户复用可继承；拒审原因回流（规格→自动修，内容→停自动提）。

### 5. 上架模块（商品×店铺矩阵 + 确定性自动修复 + 两层定价，§6）
- 商品归租户复用、上架实例归店铺独立（products/product_skus/shop_listings/shop_listing_skus）；
- 上架闸门：确定性修复自动（标题规范化/违禁词/图片修复/SKU映射/运费模板/重试），**修复后必须重过闸门**；资质/版权/定价/复杂拒审/跨店差异转人工；P0 偏人工保守；
- 两层定价：选品估算价（淘汰亏本）→ 上架前最终定价（按店/SKU/竞品/成本底价），存 pricing_decision；P0 最终价人工确认；
- 完整 SKU 粒度：毛利逐 SKU 判断；亏本/缺数据 SKU 可关闭；P0 每商品 2~3 SKU 克制。

### 6. 托管投放（店级计划 + CID 出价 + 严于上架人工边界，§7）
- 粒度 tenant→account→shop→shop_listing→ad_campaign；每 shop_listing 独立投放计划；账号层只管汇总/登录态/限流，不跨店混 ROI；
- CID 公式版本化：广告前利润 M、盈亏ROI N、目标ROI O、预估出价 P、扣回传最高出价 V、扣回传最高ROI出价 X；feedback_coefficient 命名（避免误作订单数）；
- 第一笔目标 ROI 系统生成+缓冲+0.1，人工确认预算/止损后才启动；
- 自动调节 P0 只做读报表/算ROI/硬止损自动暂停；换素材/调ROI/加预算转人工；
- **投放比上架更严**：启动/恢复/加预算/改ROI 人工确认；报表回读/预算监控/硬止损暂停系统自动。

### 7. 回读与 ROI 闭环（实测窗口 + 明细回写分层聚合，§8）
- P0-3 实测平台报表更新节奏后配置回读间隔，不预设；「两次回读」必须是两个不同数据版本；
- 区分抓取周期与决策窗口；
- 归因粒度：shop_listing_sku→shop_listing→ad_campaign→shop；明细回写+分层聚合（商品评分/类目评分/素材评分/SKU毛利/店铺策略）；新投放数据先更新商品级，达最小样本后才影响类目评分。

### 9. 监控与告警（四级分层 + 多渠道 + 防风暴，§10）
