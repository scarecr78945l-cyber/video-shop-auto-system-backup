# _interop 交接状态（方案1：共享工作区 + token 接力）

> 本目录是 DSH(DeepSeek) 与 Codex(OpenAI) 的**文件接力交换区**。半自动：一侧写完，需用户/另一侧手动通知或触发扫描。目标是把「用户在两个 AI 之间传话」降到最小。

## 目录结构与约定

```
_interop/
  STATE.md             ← 当前轮到谁、规则、下一步（双方都读这里）
  from-dsh/            ← DSH 侧所有（Codex 只读）
  from-cdx/            ← Codex 侧所有（DSH 只读）
```

- **单向所有权**：DSH 只写 `from-dsh/`；Codex 只写 `from-cdx/`。严禁改写对方侧文件（只读对方的）。
- **命名规则**：`round-NN-<role>-<主题>.md`，NN 递增，机器可排序、可去重。
- **换手标记**：每一轮产出方，在文件尾写一行
  `<!--RELAY: 请 <DSH|CDX> 读取本文件并继续，当前轮次 round-NN-->`
  对方读到该标记即接棒。
