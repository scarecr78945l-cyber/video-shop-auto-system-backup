# M0 基座与数据治理 · 模块任务书（brief）

> 由本模块总工程师填写（对照宪法第 2 节）。
> 必读设计文档：09-数据模型与任务编排.md、10-风险合规与风控清单.md、11-里程碑与落地路线.md、02-半成品项目评估.md、03-系统总体架构设计.md、01-开源项目盘点与借鉴.md
> 迭代版本：v0.1（筹备轮，2026-08-28）

## 一、模块目标

为全系统（M1~M5）提供统一的数据基座与运行骨架：**共享数据模型（`workflow_jobs`/`tasks`/`logs`/`app_config`/错误码表）治理、任务队列与调度器、资金与平台风控硬约束、环境与工程基座（环境变量化/密钥脱敏/DB 迁移/pytest 约定）、跨模块数据契约治理**——让各业务模块只管业务，保证全系统「可回滚、可审计、可观测、可一键全停」。

## 二、范围与边界

- **负责**：
  1. 共享表治理：`workflow_jobs`、`tasks`、`logs`、`app_config`（扩展）、错误码表 `error_codes` 的 Schema、归属与「共享表只读」约定；
  2. 任务队列与调度器：WorkflowJob 阶段/状态机、错误分类与重试策略、租约、幂等约束、失败隔离、调度器进程化方案；
  3. 风控与合规落地：预算三重硬约束、自动止损、余额检测、熔断探针、一键全停（后台总开关）；
  4. 环境与工程基座：硬编码路径环境变量化、密钥脱敏（`_redact_text`）、SQLite→PostgreSQL 迁移设计、pytest `--basetemp` 约定、日志留痕规范；
  5. 跨模块数据契约治理：数据字典统一、字段口径核对（经 `data-audit.md` 与 `_management/data-exchange/` 载体，宪法第 5 节）。

- **不负责**：
  - 各业务模块的表与业务逻辑（`products`/商品库 → M1；`asset_*` → M2；`image_*` → M3；上架/`wechat_openapi` → M4；`ad_*` → M5）——只规划它们与共享表的接口，不实现其业务；
  - 浏览器自动化的具体采集/上架/投放实现（属 M1~M5）；
  - git 与备份（总控唯一执行，宪法第 7 节）。

- **依赖其他模块**：
  - M1~M5 提供业务事件/数据（用于跨模块数据契约核对）；
  - 总控提供迁移包（`app.sanitized.db` → `backend/app.db`，含 498 products 基线）与共享浏览器登录态环境（11 文档前置条件）。

- **对外提供**：
  - 共享表 DDL（`workflow_jobs`/`tasks`/`logs`/`app_config`/`error_codes`）与读写约束；
  - 错误码表与重试策略约定（全模块统一引用，宪法第 8 节）；
  - 环境变量命名注册表（不含明文值）与 `.env.example` 模板；
  - 队列入队/查询 API 契约（enqueue/claim/complete/fail 语义）；
  - 风控总开关与预算约束配置（`app_config` 键约定）。

## 三、交付物清单

| 交付物 | 验收标准 |
|---|---|
| 共享表 DDL（`database/` 目录，SQLite+PostgreSQL 双方言） | 与 09 文档表清单一致；含唯一约束/索引/租约字段；迁移脚本可执行 |
| `workflow_jobs` 状态机与错误码表 | 覆盖 09 文档全部 stage 与 8 类错误码；重试策略可配置（`error_codes` 表种子） |
| 调度器设计（进程化） | 账本/节流/熔断/降频/断点续跑机制与 09 文档一致；进程重启自愈方案 |
| 风控落地清单 | 预算三重硬约束/止损/余额/一键全停逐条实现路径（`app_config` 键+代码位置） |
| 环境变量注册表（`context/`） | 全部硬编码项环境变量化；无明文值；`.env.example` 模板 |
| 密钥脱敏规范 | `_redact_text` 覆盖所有日志输出；审计无密钥 |
| SQLite→PostgreSQL 迁移设计 | 迁移计划/方言差异清单/回滚方案（`database/migrations/`） |
| pytest 约定 | 统一 `--basetemp=".pytest-tmp"`（P-001）；`backend/README.md` 测试命令已更新 |
| 数据字典与跨模块契约（`context/`） | 字段口径（金额/时间/ID/枚举）全系统一致；`data-audit` 登记齐全 |
