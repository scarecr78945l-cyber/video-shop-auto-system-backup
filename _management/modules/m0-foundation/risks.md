# M0 基座与数据治理 · 风险预判清单（risks）

> 开工前由总工程师撰写，覆盖：**登录态/账号、外部 API、浏览器自动化、数据口径、环境依赖、风控合规**。
> 已知全局风险见 `_management/logs/pitfall-log.md`（P-001~P-007），本清单引用编号并补充 M0 视角。
> 每条：风险 | 影响 | 概率 | 应对方案。

## 一、登录态与账号

| # | 风险 | 影响 | 概率 | 应对方案 |
|---|---|---|---|---|
| R01 | 共享 Chrome 登录态过期（`AUTH_REQUIRED`） | 采集/上架/投放全链路失败 | 高 | 错误分类不自动重试 → 转人工登录 → 断点续跑；登录态隔离（复用已有标签页，不重复开页）；浏览器资料不入库不上传（P-002） |
| R02 | 多平台多端口登录态管理混乱（共享 9223 / 有米云 9555 等） | 误用错误浏览器、串号 | 中 | 端口/profile_dir 注册表进配置；`probe-browsers` 巡检；一来源一 `profile_dir`（登录态隔离） |
| R03 | 验证码弹出（`VERIFICATION_REQUIRED`） | 单任务阻塞 | 中 | 单任务暂停（60min 等人工），**不阻塞其他任务排队**（失败隔离）；用户完成后面向断点续跑（09/10 文档） |

## 二、外部 API 与接口

| # | 风险 | 影响 | 概率 | 应对方案 |
|---|---|---|---|---|
| R04 | 微信小店 OpenAPI 签名/时间戳/配额 | 上架失败、限流 | 高 | 自写薄封装（SHA256 签名+时间戳窗口）；幂等重试+限额队列；`RATE_LIMIT` 180s 退避（01/09 文档） |
| R05 | AI API（DeepSeek/Kimi/Wan）密钥泄漏/额度超支 | 安全事件、成本失控 | 中 | 密钥仅环境变量；日志 `_redact_text` 脱敏；调用留痕 `ai_generation_logs`；纳入预算约束 |
| R06 | 投放/选品数据无官方 API | 只能 UI 自动化 | 高（既定） | 双轨制：上架 OpenAPI 主/UI 兜底；投放 Playwright + 探针 + 必要时半自动降级（01/03 文档） |

## 三、浏览器自动化

| # | 风险 | 影响 | 概率 | 应对方案 |
|---|---|---|---|---|
| R07 | 平台 UI 改版选择器失效（`page_changed`） | 采集/上架/投放崩 | 高 | 选择器/URL 全配置化；`page_changed` 检测留证据 + 人工接管；上架主链走 API 不受影响（P-003） |
| R08 | CDP 端口冲突/浏览器未启动 | 采集失败 | 中 | `launch-browsers` 幂等启动；端口环境变量化；探针巡检 |
| R09 | 浏览器资料（登录态）被误提交 | 账号安全 | 低 | 浏览器资料不入库不上传；`.gitignore` 排除（宪法 7/10 文档） |

## 四、数据口径与污染

| # | 风险 | 影响 | 概率 | 应对方案 |
|---|---|---|---|---|
| R10 | 多模块共库/互读写 | 脏数据扩散 | 高 | 一模块一库 + 表前缀 + 共享表只读 + `data-audit.md` 审计（P-005，宪法 4/5 节） |
| R11 | 字段口径不一致（金额单位/时间格式/ID 来源/枚举值） | 报表错、跨模块对接错 | 高 | M0 数据字典定稿：金额=元(Float)、时间=UTC timestamptz、ID=自增整数、枚举=snake_case；跨模块会签核对 |
| R12 | 并发重复入队/重复上架 | 幂等破坏 | 中 | `(product_id, stage, generation_version)` 唯一约束；指纹认领表；全部写入幂等（09 文档） |
| R13 | `tasks` 表结构与迁移包实际 DDL 不一致 | 迁移失败 | 中 | 迁移包落地后立即核对（`app.sanitized.db` → `backend/app.db`），以实际 DDL 为准修订规划 |

## 五、环境依赖

| # | 风险 | 影响 | 概率 | 应对方案 |
|---|---|---|---|---|
| R14 | pytest 默认临时目录无权限（WinError 5） | 测试全挂 | 已发生（P-001） | 统一 `--basetemp=".pytest-tmp"`；`backend/README.md` 与各模块任务书注明（本轮已落实 README） |
| R15 | Python/依赖版本不一致（半成品为 pydantic 1.10 / FastAPI 0.103） | 兼容性崩 | 中 | Python 3.12 锁定；requirements 固定版本；老依赖升级评估（02 文档） |
| R16 | 硬编码路径/密钥散落（便携 Chrome 等） | 换机器即炸、日志泄漏 | 高 | 全部环境变量化 + 脱敏（P-004）；`.env.example` 模板（不含值） |
| R17 | ffmpeg/Playwright/浏览器未就绪 | 素材/浏览器链路断 | 中 | 11 文档前置条件清单；启动自检脚本 |

## 六、风控与合规

| # | 风险 | 影响 | 概率 | 应对方案 |
|---|---|---|---|---|
| R18 | 批量上架/托管集中操作触发平台风控 | 验证码/封禁 | 高 | ≤50/批串行 + 批间隔可配；节流 0~4 级退避；熔断探针；上架与投放节奏错峰；一键全停（P-006，10 文档） |
| R19 | 投放花费失控 | 资金损失 | 高 | 预算三重硬约束（单笔/日/计划同时生效，任一超限即停）；自动止损（0 成交+曝光达阈值 → 暂停打标签；ROI<目标×80% 持续 2 周期 → 降档）；余额检测（<¥100 停新托管+告警）；一键全停（10 文档） |
| R20 | 内容合规（品牌侵权/功效资质/虚假宣传/供应链词） | 拒审、法律风险 | 高 | 复用 `compliance.py` 三态过滤；类目白名单配置化；素材版权标注与二创义务；人工闸门（10 文档） |
| R21 | 管理后台无鉴权（当前 API 全开放） | 越权操作 | 高 | 管理后台登录鉴权；CORS 收口（02/10 文档，宪法 8 节） |
