# M3 自动素材优化 · 模块任务书（brief）

> 由本模块总工程师填写（对照宪法第 2 节）。
> 必读设计文档：06-自动素材优化模块设计.md、09、10、11、03；关联：05（M2 素材契约）、08（M5 消费契约）、04（M1 商品信息）。
> 版本：v0.1（筹备完成，待总控确认后进入开发）

## 一、模块目标

一句话：把 M2 入库的原始素材（视频/图片）与 M1 商品信息（淘宝原始标题、1688 SKU 规格、类目），
经 **LLM 拆解/规划/生成 + ffmpeg 批量处理**，产出**三路合规优化素材**（9:16 视频二创多版本、主图/详情图、文案多套），
通过审核闸门后交付 M4 上架与 M5 投放消费，并以**评估标签回流 + 模板参数按类目重训练**形成 A/B 优化闭环。

## 二、范围与边界

### 负责（6 条）

1. **视频二创流水线**：LLM 拆解卖点镜头/口播要点 → 模板化二创（片头/中段/片尾三段式）→ 文案叠加（标题/角标/字幕）→ ffmpeg 批量出片 9:16 多版 → 硬规格校验 → 合规预审 → 上传小店素材库拿素材 ID + 评估标签。
2. **主图/详情图管线**：Kimi 规划视觉策略（KimiImagePlanner）→ Wan 生图（WanImageProvider）→ 质量门禁（image_quality_gate）→ 人工/规则审核 → 类目记忆（category_listing_memory）累积。
3. **文案管线**：商品标题 15–35 字符机械清洗；卖点口播稿（仅基于 1688 SKU 真实规格）；投放文案/角标多套候选；合规预审。
4. **审核闸门**：规则预审（品牌侵权/功效资质/虚假承诺/供应链词）→ 素材评估（平台诊断回读）→ 人工复核抽检（配置化百分比，高风险类目强制）。
5. **A/B 优化闭环**：单商品产出 ≥2 版素材；M5 效果回写 evaluation（高效/潜力/探索期）；素材评分排序；模板参数按类目重训练。
6. **上传小店素材库**：获取 platform_material_id + 平台评估标签；失败按错误码分类重试/转人工。

### 不负责

- 原始素材采集/去重/标准化入库（M2）
- 选品、询价、打分（M1）
- 商品上架执行（M4）
- 投放计划/执行/报表回读（M5）

### 依赖其他模块

| 依赖 | 内容 | 方式 |
|---|---|---|
| M0 基座 | workflow_jobs / tasks / logs / app_config / ai_generation_logs | 共享表**只读**，写入经总控协调 |
| M1 选品 | product 信息：淘宝原始标题、类目、1688 SKU 规格/材质 | 数据联动（见 context/data-requests.md） |
| M2 素材 | assets 素材库：原始视频/图片 + 标签 + 热度 + 双去重 | 数据联动（只读 assets 或 data-exchange JSON） |
| M5 投放 | 曝光/花费/成交/诊断 → evaluation 回写 | 数据联动（回写 opt_evaluation_feedback） |

### 对外提供

| 消费方 | 提供内容 |
|---|---|
| M4 上架 | 主图 5 张（1:1 且不全相同）+ 详情图 ≥3（标准 3+3）+ 标题（15–35 字符）+ 可选口播稿 |
| M5 投放 | 9:16 视频多版本（A/B 候选，file_path + platform_material_id）+ 投放文案/角标 + evaluation 标签排序 |
| 总控 | 素材质量统计、拒审原因统计、模板参数训练结果、上传成功率 |

## 三、交付物清单

| # | 交付物 | 验收标准 |
|---|---|---|
| 1 | 视频二创流水线（backend/optimization/video/） | 输出满足硬规格：≥720×1280｜9:16｜MOV/MP4｜≤500M｜5~300s；单商品 ≥2 版；三段式（片头/中段/片尾）；字幕/角标/水印合规预审通过；ffprobe 校验留证据 JSON |
| 2 | 主图/详情图管线（backend/optimization/images/） | 主图 5 张 1:1 且不全相同（phash 校验）；详情图 ≥3（最低门槛 1+1 可放行，标准 3+3）；质量门禁统计可观测；类目记忆按类目累积「人工通过/平台拒审」经验并反哺生图策略 |
| 3 | 文案管线（backend/optimization/copywriting/） | 标题 15–35 字符且不虚构卖点（淘宝原始标题为唯一来源）；口播稿仅基于 1688 SKU 真实规格；投放文案/角标 ≥2 套候选且合规预审通过 |
| 4 | 审核闸门（backend/optimization/review/） | 规则预审（品牌/功效/虚假承诺/供应链词）→ 素材评估 → 人工抽检（百分比配置化，高风险类目强制）；PLATFORM_REJECT 记录原因转人工 |
| 5 | A/B 优化闭环（backend/optimization/ab/） | 单商品 ≥2 版；evaluation 回写正确落库；素材评分 = f(成交 ROI, 曝光点击率, 诊断)；模板参数按类目重训练脚本可跑 |
| 6 | 小店素材库上传（backend/optimization/upload/） | 上传成功拿 platform_material_id + 评估标签；失败按错误码（AUTH_REQUIRED / RATE_LIMIT / PLATFORM_REJECT / TIMEOUT…）分类处理，≤50/批串行 |
| 7 | 模块数据库 | opt_* 表 DDL + 迁移脚本（database/README.md）；与 M2/M5 字段口径经 data-audit.md 核对 |
| 8 | 测试套件 | pytest 全绿（`--basetemp=".pytest-tmp"`，P-001）；覆盖出片规格校验、合规预审、文案长度、幂等重试、A/B 回写 |
