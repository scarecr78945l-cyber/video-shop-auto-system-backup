# M3 自动素材优化 · 风险预判清单（risks）

> 开工前由总工程师撰写（v0.1）。格式：风险 | 影响 | 概率 | 应对方案。
> 关联全局踩坑：P-001（pytest basetemp）、P-002（登录态失效）、P-003（UI 改版选择器失效）、P-004（密钥散落）、P-005（多模块共用单库）、P-006（批量集中操作风控）、P-007（素材不合规格拒审）。
> 每条应对必须在代码/文档中落实（宪法第 8 节）。

## 一、LLM API（DeepSeek / Kimi / Wan）密钥与配额 ★重点

| 风险 | 影响 | 概率 | 应对方案 |
|---|---|---|---|
| DeepSeek Key 缺失/过期 | 卖点拆解、口播稿、文案候选链路全断 | 中 | 环境变量 `DEEPSEEK_API_KEY`；模块启动自检，缺失时日志告警并降级为规则模板文案（不阻塞出片/生图） |
| Kimi Key 缺失/配额不足 | 主图视觉策略退化为默认模板 | 中 | 环境变量 `KIMI_API_KEY`；规划失败 → 使用默认策略（白底+商品图+卖点角标）并记录 ai_generation_logs |
| Wan 生图限流/配额耗尽 | 生图失败或排队过长 | 中 | RATE_LIMIT 按 180s 退避（复用错误码体系）；日配额预算熔断（opt 配置），超限转人工排队 |
| LLM 输出非结构化/解析失败 | 管线中断、脏数据入库 | 中 | 全部走结构化输出（JSON Schema）；解析失败重试 2 次 → 记录失败原因 → 丢弃该候选 |
| API 成本失控 | 预算超支 | 低 | 每次调用记录 token/费用到 ai_generation_logs；日成本阈值告警，超限熔断 |
| 密钥落日志/落文档 | 凭证泄漏 | 低 | 密钥只写**环境变量名**；日志统一 `_redact_text` 脱敏（P-004）；禁止任何明文写入 md/代码/日志 |

## 二、ffmpeg 输出硬规格校验 ★重点

| 风险 | 影响 | 概率 | 应对方案 |
|---|---|---|---|
| 出片分辨率/比例不合规（非 9:16、<720×1280） | 平台拒审/无法绑定投放 | 中 | 出片后强制 `ffprobe` 校验 resolution/ratio/duration/size；不合格自动重转（scale+pad 模板）或丢弃并记录；校验结果 JSON 留证据（P-007） |
| 超大小（>500M）/超时长（>300s） | 上传失败/拒审 | 低 | 编码参数锁定（libx264 -crf 23 / aac，可配置）；时长裁剪上限 300s；大小超限提高 crf 重转 |
| ffmpeg/ffprobe 未安装或版本过旧 | 视频链路全断 | 低 | 启动自检 `ffmpeg -version`；`FFMPEG_PATH`/`FFPROBE_PATH` 配置化；缺失则视频链路禁用并告警，不影响图片/文案链路 |
| 批量出片资源占用/并发崩溃 | 机器卡死、任务丢失 | 中 | 出片队列并发数配置化（默认 2）；任务入 workflow_jobs 可断点续跑（租约/失败隔离） |

## 三、生图质量与平台拒审 ★重点

| 风险 | 影响 | 概率 | 应对方案 |
|---|---|---|---|
| 主图 5 张雷同 | 质量门禁拦截、上架失败 | 中 | 生成时注入差异化 prompt 策略（角度/背景/卖点焦点）；门禁 phash 相似度检测，重复则重生成 |
| 生图质量差（糊/畸形/水印残留） | 平台拒审 | 中 | image_quality_gate 门禁（分辨率/清晰度/完整性）；不合格打回重生成，重试次数上限后转人工 |
| 拒审原因未沉淀 | 同类错误反复发生 | 中 | 拒审原因回写 opt_category_memory（类目记忆）：按类目累积「人工通过/平台拒审」经验，自动调整生图策略与 prompt |
| 图片尺寸/数量不合规 | 上架校验失败 | 低 | 主图 1:1 五张且不全相同；详情图 ≥3；生成后强制校验尺寸/格式/数量 |

## 四、供应链词 / 品牌词合规 ★重点

| 风险 | 影响 | 概率 | 应对方案 |
|---|---|---|---|
| 字幕/角标/主图出现供应链词（1688/工厂/源头/厂家/一件代发/批发） | 平台拒审/低质 | 中 | 双重保险：LLM 生成指令明确禁用 + 生成后 compliance 规则过滤（复用并扩展 `compliance.py` 词库）；命中即该版本作废重生成 |
| 品牌词 /「同款」/「官方旗舰」/功效词 | 侵权/资质拒审 | 中 | 复用 BRAND_WORDS / EFFICACY_WORDS 词库前置过滤；口播稿只引用 1688 SKU 真实规格，来源未证实的承诺（如赠品数量）不保留 |
| 素材版权（搬运素材） | 平台处罚 | 中 | 只处理 M2 标记「可二创」来源的素材；二创义务落实（去水印/混剪/换文案）后才可出片 |

## 五、评估标签回流口径 ★重点

| 风险 | 影响 | 概率 | 应对方案 |
|---|---|---|---|
| evaluation 标签（高效/潜力/探索期）口径不一致 | 素材排序失真、模板训练污染 | 中 | 口径写入 context 数据字典 + data-audit.md 登记；M5 回写统一经 opt_evaluation_feedback（素材 ID + 曝光/花费/成交/ROI/诊断），**M3 计算标签，不直写 M2 的 assets 表**（总控协调同步） |
| 回写数据缺失/延迟 | 模板训练用陈旧数据 | 中 | 按 report_date 日快照聚合；无数据时沿用上一标签并标记 stale=1；评分函数无数据返回「探索期」默认 |
| 素材 ID 映射错乱 | A/B 数据串线 | 低 | 每版素材唯一 (product_id, variant_no)；回写按 platform_material_id ↔ 本地 variant_id 双映射校验 |

## 六、上传小店素材库（接口/UI 方式）★重点

| 风险 | 影响 | 概率 | 应对方案 |
|---|---|---|---|
| 素材上传 OpenAPI 接口不存在（仅 UI） | 无法全自动拿素材 ID | 中 | 先验证小店 OpenAPI 是否有素材上传接口；无则 Playwright UI 兜底（选择器配置化 + page_changed 检测留证据 + 人工接管，P-003）；仍不可用则降级半自动（系统预填，人工点上传） |
| 上传需小店后台登录态 | AUTH_REQUIRED 全断 | 中 | 共享 Chrome（CDP 9223）登录态复用；失效 → 不自动重试 → 人工登录 → 断点续跑（P-002） |
| 批量上传触发平台风控 | 账号风险 | 中 | ≤50/批串行 + 节流退避 0~4 级（P-006）；失败按 RATE_LIMIT 处理，不阻塞其他任务 |

## 七、数据口径与污染

| 风险 | 影响 | 概率 | 应对方案 |
|---|---|---|---|
| 直接读写其他模块库 | 数据污染（P-005） | 低 | 一模块一库铁律；M2 `assets` / M1 `products` 只读引用；所有产出写 opt_* 表；跨模块取数走 data-requests.md + data-audit.md 审计 |
| 生成任务重复执行 | 重复出片/重复生图浪费成本 | 中 | (product_id, stage, generation_version) 唯一约束 + 幂等写入（复用 WorkflowJob 机制） |
| 09 文档既有表 image_batches/image_assets 与 M3 生图职责归属不清 | 表语义冲突/双写 | 低 | 已登记 decisions.md 待总控裁定；当前规划 M3 自建 opt_image_* |

## 八、环境依赖

| 风险 | 影响 | 概率 | 应对方案 |
|---|---|---|---|
| Python 版本不匹配（需 3.12+） | 依赖安装失败 | 低 | requirements.txt 锁定；运行前版本校验 |
| pytest 临时目录权限（P-001） | 测试全红误判 | 低 | 统一 `python -m pytest tests -q --basetemp=".pytest-tmp"` |
| ffmpeg 缺失（见第二节） | 视频链路断 | 低 | 启动自检 + 配置化路径 |
| 网络不可达（LLM/生图/上传） | 全链路断 | 中 | 错误分类 TIMEOUT 60s 退避重试；断点续跑（resume_on_startup） |
