# M4 自动上架 · 风险预判清单（risks）

> 开工前由总工程师撰写。预判方向必须覆盖：**登录态/账号、外部 API、浏览器自动化、数据口径、环境依赖、风控合规**。
> 每条格式：风险 | 影响 | 概率 | 应对方案。已知全局风险见 _management/logs/pitfall-log.md（P-001 起），本清单引用不重复展开。

## 一、OpenAPI 准入条件与账号（登录态/账号）

| # | 风险 | 影响 | 概率 | 应对方案 |
|---|---|---|---|---|
| R1 | **企业主体/类目资质未开通**：channels OpenAPI 要求企业主体 + 类目资质审核通过，个体户/未开通类目直接报错 | 创建类操作全部失败，全队阻塞 | 高（上线初期） | 前置「准入体检」脚本：启动时核对主体类型、类目白名单（app_config 配置化，现 9 类）、资质完整性；未达标商品标记 `PLATFORM_REJECT` 不入队；类目开通清单维护在 context/外部契约 |
| R2 | **access_token 生命周期**：微信 token 约 2 小时过期，多线程并发刷新冲突 | 请求 40001/42001，批量失败 | 中 | token 集中缓存 + 单例刷新（锁）+ 提前 5min 预刷新；刷新失败转 `AUTH_REQUIRED` 人工接管 |
| R3 | **共享 Chrome 登录态失效（兜底链路）**：P-002 | UI 兜底操作全部失败 | 中 | `AUTH_REQUIRED` 不自动重试 → 人工登录 → 断点续跑；登录态隔离（复用已有标签页，不重复开页）；浏览器资料不入库不上传 |

## 二、外部 API 与接口（签名/配额/轮询）

| # | 风险 | 影响 | 概率 | 应对方案 |
|---|---|---|---|---|
| R4 | **接口调用配额**：微信对每接口有 QPS/日配额限制，批量上架易触发 | RATE_LIMIT 大量重试，排队恶化 | 高 | 按接口维度**令牌桶**（写入请求排队，读接口放宽）；RATE_LIMIT 180s 退避；限额参数全配置化（app_config）；熔断探针：连续失败 ≥2 暂停该接口 |
| R5 | **SHA256 签名 + 时间戳窗口失效**：本机时钟偏差超窗口即签名校验失败 | 全部请求被拒（403），难排查 | 中 | 启动时 NTP/HTTP 头校时；失败分类 `UNEXPECTED` 并留证据（含本地时间 vs 服务器时间差值）；签名算法单测锁定 |
| R6 | **非幂等重复提交**：重试/断点续跑导致重复创建 SPU/SKU | 平台出现重复商品 | 中 | `(product_id, stage, generation_version)` 唯一约束（09 文档）；请求携带幂等键；创建前按平台商品 ID 反查去重 |
| R7 | **审核状态轮询**：query_audit_status 轮询间隔/超时/接口不稳定 | 状态误判或轮询风暴 | 中 | 轮询间隔可配（默认 60s）、单任务轮询上限 + TIMEOUT 60s 退避；**状态只以查询结果为准，禁止猜测**；未知状态保持「平台审核中」不迁移 |
| R8 | **平台驳回（PLATFORM_REJECT）**：资质/内容/图片原因驳回 | 商品滞留审核驳回态 | 中 | 记录驳回原因（原因分类表）+ 自动修复候选（标题/图片重传等）+ **二次门禁**后才可重新提交；不可自动修复转人工 |
| R9 | **COS 直传（upload_image）失败/素材 ID 失效** | 主图缺失导致创建失败或审核驳回 | 低 | 上传幂等（文件哈希去重）；返回 media_id 入库（listing_upload_assets）；上传失败走 TIMEOUT/UNEXPECTED 退避重传 |

## 三、浏览器自动化（Playwright 兜底）

| # | 风险 | 影响 | 概率 | 应对方案 |
|---|---|---|---|---|
| R10 | **选择器脆弱/页面改版**：P-003，官方未覆盖操作依赖 UI | UI 兜底通道崩溃 | 高 | 上架主线走 OpenAPI，UI 仅处理 API 未覆盖尾巴；选择器/URL 全配置化（config 文件）；`page_changed` 检测 + 截图留证据 + 人工接管；**UI 失败不阻塞 OpenAPI 队列** |
| R11 | **UI 兜底误操作**（点错按钮/覆盖已有配置） | 商品状态被破坏 | 低 | 降低兜底频次；写操作双重确认（前置断言 + 结果断言）；失败回滚到断点，不留半成品状态 |

## 四、数据口径与污染

## 六、风控与合规

| # | 风险 | 影响 | 概率 | 应对方案 |
|---|---|---|---|---|
| R19 | **上架与托管批量集中触发平台风控**：P-006 | 验证码/封禁 | 中 | ≤50/批串行、批间隔可配、节流 0~4 级退避（×1/2/4/8/16）、熔断探针（连续失败进 risk_control 暂停平台）；**上架与托管节奏错峰**（上架批次与 M5 托管提交互斥时段，错峰参数可配）；一键全停 |
| R20 | **内容违规拒审**：品牌词/「同款」/「代言」/功效词/供应链词 | 拒审率高、账号风险 | 中 | 复用 compliance.py 预审：品牌/功效/供应链词过滤（10 文档第三节）；标题 15–35 字符且非虚构承诺；门禁强制合规预审通过 |
| R21 | **素材不合规格**：P-007，主图不足 5 张/非 1:1/不全相同、详情图缺失 | 创建失败/拒审 | 中 | 门禁逐项校验（≥5 张 1:1、去重比对、详情图完整性），失败不入队；素材规格写进跨模块契约 |
| R22 | **真实链接验证铁律被绕过**：内部状态冒充已上架 | 前端显示已上架但链接不可访问，销售承诺落空 | 低（纪律风险） | **仅** `get_product_link` 返回 + HTTP 可达（200 且页面含商品标识）才置「已上架」；验证失败回「平台审核中」并记录证据；代码评审 + 单测固化该断言 |
| R23 | **人工闸门缺失**：新类目/新供应商直接自动上架 | 违规商品上架 | 中 | 默认新类目/新供应商需上架最终确认（人工闸门，10 文档第五节）；稳定类目按通过率达标自动放行（可配置） |
| R24 | **验证码**：VERIFICATION_REQUIRED 单任务暂停 | 单任务阻塞 | 中 | 单任务暂停不阻塞队列；用户完成后断点续跑；不自动重试 |

## 七、风险登记纪律

- 新增风险发现即在本表追加（编号 R25 起），并在 pitfall-log.md 登记为 P-0xx（若属全局/环境级）。
- 风险处置措施必须落实到代码/配置/文档，防止「只写在纸上」。
- 当前无未决阻塞；若 OpenAPI 实际契约与文档不符（签名参数名/接口路径/配额阈值），按宪法第 6 节写入 BLOCKERS.md 并结束回合等待总控协调获取官方文档核对。
