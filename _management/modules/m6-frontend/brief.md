# M6 前端控制台 · 模块任务书（brief）

> 由本模块总工程师在开工前填写（对照宪法第 2 节）。

## 一、模块目标

（待总工填写：Next.js + React + Tailwind 管理控制台：商品队列/素材库/上架任务/托管看板/图片审核工作台/异常中心/周报）

## 二、范围与边界

- 负责：前端工程 + 后端 API 消费层（FastAPI）对接 + 旧系统组件复用（P1-7）
- 不负责：业务逻辑（归 M1~M5）；数据库（只读消费后端 API）
- 依赖其他模块：M1~M5 的 API 契约；M0 的鉴权/审计
- 对外提供：管理控制台（人工闸门入口：选品复核/上架确认/素材预审/验证码接管）

## 三、交付物清单

| 交付物 | 验收标准 |
|---|---|
| 前端工程（Next.js 脚手架） | 可启动、路由就绪 |
| 后端 API 层（FastAPI） | 各模块能力暴露 + 鉴权 |
| 看板/队列/素材/上架/托管页面 | 数据可展示、人工操作可用 |
| 人工闸门工作台 | 复核/确认/接管流程可用 |

| 阶段 | 任务 | 迭代版本 | 完成标准 |
