## 一、模块目标

建设 **视频号微信小店全自动系统 · 管理控制台（Next.js + React + Tailwind）**，全系统唯一人机界面，覆盖：

1. **总览看板**：任务队列统计（workflow_jobs 按 stage/status/error_code 聚合）、预算/风控状态（S8 一键全停总开关、S5 余额告警）、错误码分布、今日漏斗（选品→询价→生图→上架→托管）。
2. **商品队列/素材库**：M1 商品池（五维打分可解释）、M2 素材库（双去重/相关性门/评估标签/上传状态）。
3. **上架任务**：M4 上架状态机（9 态）列表与详情、上架包确认、拒审修复/重提。
4. **托管看板**：M5 商品托管列表，对齐后台列（商品/目标出价/诊断/曝光/花费/成交/补贴/操作），报表快照与止损状态。
5. **人工闸门工作台**（合规兜底，10 文档第五节 + 09 状态机）：
   - 选品复核（M1 manual_review → pool，可配置放松）
   - 上架最终确认（M4 pending 上架包 confirm）
   - 投放素材预审（M3 图片审核 approve/reject + M2 素材相关性 multi_style 人工确认目标款）
   - 验证码/登录接管（VERIFICATION_REQUIRED / AUTH_REQUIRED 任务单任务暂停与恢复）
6. **异常中心**：blocked/waiting_login/waiting_verification 任务清单、重试/断点续跑入口、一键全停。

## 二、范围与边界

- **负责**：
  1. 后端 API 层（`backend/api/`，FastAPI）：聚合 M0~M5 的 repo/服务能力，**唯一取数通道**（前端不直连任何模块库）；补管理后台鉴权（10 文档第六节「当前 API 全开放，需补」）。
  2. 前端工程（`frontend/`，Next.js 15 + React 19 + Tailwind 3）：脚手架、路由、状态管理、数据展示与人工操作。
  3. 旧系统组件复用改造（P1-7：ImageReviewPanel/ListingManagerView/StageQueueView/ExceptionCenter/ProviderSettings/lib api.ts/workflow.ts）。
  4. 展示口径转换层：金额分→元、时间 UTC→UTC+8、枚举中文映射（REC-005/DA-001）。
- **不负责**：业务逻辑（归 M1~M5）；数据库读写（只读消费后端 API 层）；调度/采集/投放执行（归各模块）。
- **依赖其他模块**：M1~M5 的 repo/数据访问层能力（经 API 层聚合，接口契约由 M6 起草、各模块总工会签）；M0 的鉴权/审计/脱敏（foundation/security.py 语义对齐）；总控协调跨模块取数（data-audit 登记）。
- **对外提供**：管理控制台全部页面 + 人工闸门操作入口 + 一键全停（S8）前端总开关。

## 三、技术选型与架构要点

| 项 | 选型 | 说明 |
|---|---|---|
| 前端框架 | Next.js 15（App Router）+ React 19 + TypeScript 5.7 | 与旧系统同栈（P1-7 结论「Next.js 同栈」），组件可直接搬 |
| 样式 | Tailwind CSS 3.4 + tailwind-merge + clsx + cva | 旧系统已用，组件样式零迁移 |
| 图标 | lucide-react | 旧系统已用 |
| 测试 | vitest 4（组件/工具单测）+ Playwright（e2e 可选） | 旧系统已用 vitest |
| API 层 | FastAPI（Python 3.12）+ pydantic v2 + SQLAlchemy 2.0 | 与后端技术栈一致；聚合各模块 repo |
| 鉴权 | 管理后台登录（会话 cookie httpOnly 或 JWT），登录态/密钥走环境变量，CORS 收口 | 10 文档第六节；密码只走环境变量，不落任何文件 |
| 端口 | API 8000（默认，可配）；前端 dev 3000 | 避开 8787（P-008 已被 captcha-vision-gateway 占用） |
| 数据流 | 前端 → API 层（唯一通道）→ 各模块 repo（只读）+ 人工操作写入 | 前端零直连模块库，防数据污染（宪法第 4 节） |

**数据口径（强制）**：金额一律「分」int 存储/传输，展示层 ÷100 转元；时间一律 UTC ISO8601 存储/传输，展示层转 UTC+8；枚举展示中文映射表（见 context/README.md「展示口径」）。

## 七、关键纪律（宪法要点）

1. **UTF-8 无 BOM**（宪法第 11 节）：所有 .md/.tsx/.ts/.py/.json 用 write/edit 工具写；禁止 PowerShell 重定向写中文。
2. **禁 git**：备份/推送由总控唯一执行。
3. **禁明文密钥**：API 密钥/密码只走环境变量；ProviderSettings 只显示 masked（旧系统已有 `*_key_masked` 模式沿用）；日志脱敏（对齐 M0 foundation/security.py）。
4. **敏感数据不落前端**：token 走 httpOnly cookie；API 密钥/登录态不进 localStorage；前端只存 UI 状态。
5. **小步落盘**：每完成一文件立即落盘；子代理任务书强制「第一动作写盘」；中断后先查已落盘文件再重派（P-014 防复发）。
6. **测试纪律**：后端 pytest 必须 `--basetemp=".pytest-tmp-m6"` + `-X utf8`（P-001/P-011/P-017）；前端 vitest 独立运行。
7. **跨模块取数**：API 层是唯一取数通道；契约变更经 data-audit 登记、总控核对（宪法第 5 节）。
8. **不搬旧壳**：旧前端整体框架不搬（第二波融合清单「排除」项），搬组件不搬壳。
