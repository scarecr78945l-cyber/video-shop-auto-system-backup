## 一、模块目标

**一句话**：持续从视频号/抖音/快手/小红书/淘宝/1688 等来源自动收集**9:16 竖屏视频素材（投放/投稿用）**与**图片素材（主图/详情，上架用）**，经双去重、ffmpeg 标准化、标签化与内容预审后入库素材库，为 M3 素材优化（原始素材→二创）和 M5 小店投放（素材绑定、评估标签回流）提供符合硬规格、可追溯、可复用的素材资产。

**价值定位**：素材库是全系统的"弹药库"——规格不符或版权不清的素材会直接卡死 M3 二创与 M5 投放，本模块的输出质量决定下游两个模块的上限（对应 05 设计目标与 11 里程碑 M1「素材闭环」验收项）。

## 二、范围与边界

### 负责（In Scope）
- **视频采集**：视频号达人/热门（自研采集器：签名+直链）；抖音/快手/小红书（TikTokDownloader 二次封装：批量关键词/达人主页）；淘宝/1688 商品视频（Playwright 共享浏览器抓取）。
- **图片采集**：淘宝/1688 同款图（复用 `fetch_taobao_references.py` / `fetch_1688_images.py`）；考古加/有米云榜单图顺带缓存（IMAGE_CACHE）。
- **下载中台**：多实例 HTTP API 下载服务（参考 Douyin_TikTok_Download_API 思路），支持断点、节流、熔断、重试。
- **双去重**：视频 = MD5 + 关键帧感知哈希（phash）；图片 = phash（对齐 backend `sourcing/dedup.py` 的 image_phash 口径）。
- **标准化**：ffmpeg 转码，硬规格输出（≥720×1280、9:16、MOV/MP4、≤500M、5~300s）。
- **标签化与入库**：类目/来源/达人/时长/清晰度/热度字段 → Asset 实体入库；评估标签字段（探索期/高效/潜力）由 M5 回写。
- **合规与预审**：素材版权来源标记与二创义务；复用 `compliance.py` 供应链词/品牌词过滤；平台拒审素材自动下架标记。
- **模块库**：`backend/data/db/m2-materials.db`（SQLite 开发；生产 PostgreSQL 迁移脚本放 `database/`）。

### 不负责（Out of Scope）
- 素材**二创/优化**（混剪、字幕、多版出片、文案）→ M3 模块，本模块只交付原始素材与元数据。
- **投放**、ROI 目标、素材绑定、报表回读 → M5 模块；本模块只暴露素材查询/绑定接口与评估标签写入接口。
- **选品**打分、商品池、上架 → M1/M4 模块；本模块不写 `products` 等基座/其他模块表。
- **生图**（AI 主图生成）→ M3 模块；本模块只采集/缓存参考图与榜单图。

### 依赖其他模块（只读/协作）
| 依赖 | 内容 | 方式 |
|---|---|---|
| M0 基座 | `workflow_jobs`/`tasks`/`logs` 队列与错误码体系、`app_config` 配置、共享 Chrome 登录态（CDP） | 只读 + 经总控协调写入 |

| M5 投放 | 素材评估标签回流（探索期/高效/潜力）与平台拒审/源文件损坏标记 | 数据联动协议（data-audit 登记） |

### 对外提供
- 素材库查询接口（按类目/来源/标签/规格筛选、预览、状态）
- 素材入库/去重/标准化结果事件（供 M3 拉取原始素材、M5 绑定素材）
- 评估标签写入接口（M5 回写 `asset_items.evaluation` + `asset_evaluations` 审计）
- 上传小店素材库任务（素材 ID 回流，供 M5 投放绑定）
