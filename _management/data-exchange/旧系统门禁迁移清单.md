## 四、C 类：缺口·待迁移（必须补，本清单核心）

### C1 鞋服/包类硬拦词表 → M1 compliance

- **旧系统证据**：`SOURCING_HARD_BLOCK_POLICY`（apparel_terms 200+ 词、safe_apparel_context_terms 豁免、bag_terms、safe_bag_context_terms、apparel_suffix/bag_suffix）+ `flow_orchestrator._apparel_excluded()`（鞋服命中强制 `已淘汰`，安全上下文豁免：衣架/洗衣机/收纳/客服等）
- **新系统现状**：`sourcing/compliance.py` **无鞋服/包词表**（grep 未命中 apparel 词）；`listing_gate.py` 有 PROHIBITED_WORDS 但覆盖度不足
- **迁移动作**：将 `hard-block-policy.json` 的 apparel/bag 词表挂为 compliance 配置（JSON 配置化），实现 `_apparel_excluded` 同语义判定（命中 + 非安全上下文 → hard_reject）
- **验收标准**：fixtures 用例覆盖 ①命中鞋服词→hard_reject ②衣架/洗衣机→放行 ③包词→hard_reject ④垃圾袋/收纳袋→放行；旧系统 `test_pipeline_safety.py` 鞋服断言移植

### C2 1688 客服补参闭环 → M1 alibaba + M4 listing 包校验

- **旧系统证据**：`needs_1688_customer_service` 状态；缺参字段（适用年龄/包装清单/重量/容量/适用场景/类别/功能）→ 生成问题模板「请确认该商品的{label}用于上架商品参数。」→ `build_customer_service_targets` 并行问客服 → `POST /api/alibaba/customer-service-attrs` 回填 → 缺参清零才允许上架（`open_wechat_upload_product.py` L4948/L5998）
- **新系统现状**：`sourcing/collectors/alibaba.py` **只有以图搜款+询价，无缺参/客服环节**；`listing_gate.py` 无"参数缺失阻断"
- **迁移动作**：
  1. M1 alibaba 采集结果中保留 `missing_attrs` 字段（对照 `listing-requirements.json` 的 missing_field_labels）
  2. M4 上架包校验增加 `attrs_complete` 门禁：缺参 → listing 包标记 incomplete，禁止提交
  3. 客服补参作为人工/半自动环节：OpenAPI 主链路下由人工在确认页补填，Playwright 兜底链路保留自动问客服逻辑
- **验收标准**：listing_gate 新增 gate 项 `attrs_complete`（缺任一必填参数→拒绝并列出缺项）；补参后重审通过

### C3 素材相关性门（material_gate）→ M2 采集后 + M4 候选池前重建

- **旧系统证据**：`auto_flow._collect_and_judge_materials`：有米云多关键词穷举 → 4 线程下载 → Qwen-VL 前 15 秒抽帧相关性判定 → `material_clustering` 款式聚类 → **多款式必须人工确认（禁止自动选品/采购）**；鞋服强制淘汰
- **新系统现状**：新 stage 流水线（source_collect→alibaba_quote→taobao_reference→image_generation→listing_upload→shop_ads_run）**无 material_gate 阶段**；M3 `optimization/review/gate.py` 是"规格审核"（分辨率/时长/格式），不是"与商品相关性判定"
- **迁移动作**：
  1. 复用 `optimization/review/gate.py` 框架新增 `relevance` 审核类型（Qwen-VL 判定 + 款式聚类）
  2. 在 M2 采集入库与 M4 候选池之间加数据质量门：相关性未过 → 不进入询价/上架
  3. 规则保留："多款式聚类 → 人工确认目标款，禁止自动创建衍生商品"（旧系统 08-17 修正后的收敛规则）
- **验收标准**：fixtures 素材用例覆盖 ①相关→放行 ②不相关→reject ③多款式→manual_review；聚类结果留 evidence
