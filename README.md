## 核心结论（三句话）

1. **现有半成品可复用 60% 以上**：选品调度器（账本/节流/熔断）、任务队列（失败隔离/人工接管）、定价/合规/生图链路、534 个测试，直接吸收。
2. **上架必须双轨**：主链路迁移到微信小店官方 OpenAPI，181KB Playwright 脚本降级为兜底。
3. **投放走「商品托管」**：无转化不扣费、平台自动投流，自动化只做三件事——选托管商品、设目标 ROI、绑定优选素材，成交数据回写选品与素材评分，形成闭环。
